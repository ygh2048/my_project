### 功能说明

#### 阈值设置操作流程
1. 按 **C** 键进入阈值设置模式
2. 按 **0-9** 数字键输入阈值（最多4位数）
3. 按 **#** 键确认并保存阈值（有效范围：10-9999mm）
4. 按 **\*** 键取消输入并返回

#### 按键功能表
| 按键 | 功能 |
|------|------|
| 0-9 | 输入阈值数字（需先按C进入设置模式） |
| A | 系统开机 |
| B | 系统关机 |
| C | 进入阈值设置模式 |
| D | 循环显示系统信息并蜂鸣提示 |
| \* | 取消输入/清屏 |
| # | 确认并保存阈值（10-9999mm） |
