# STM32F103C8T6 激光测距报警系统 - 引脚配置表

## 系统概述
- **MCU**: STM32F103C8T6 (LQFP48)
- **主频**: 72MHz
- **Flash**: 64KB
- **RAM**: 20KB

---

## GPIO 引脚配置

### LCD1602 (4位模式)
| 引脚 | GPIO | 功能 | 模式 |
|------|------|------|------|
| RS | PB12 | 寄存器选择 | Output_PP |
| RW | PB13 | 读/写控制 | Output_PP |
| E | PB14 | 使能信号 | Output_PP |
| DB4 | PB15 | 数据位4 | Output_PP |
| DB5 | PA8 | 数据位5 | Output_PP |
| DB6 | PA11 | 数据位6 | Output_PP |
| DB7 | PA12 | 数据位7 | Output_PP |
| DB0-DB3 | GND | 数据位0-3 | 接地 |

### 独立按键 (4个)
| 引脚 | GPIO | 功能 | 模式 | 极性 |
|------|------|------|------|------|
| KEY0 | PC13 | 确认 | Input_PU | 低 |
| KEY1 | PC14 | 减少阈值 | Input_PU | 低 |
| KEY2 | PC15 | 增加阈值 | Input_PU | 低 |
| KEY3 | PA1 | 系统开关 | Input_PU | 低 |

### 矩阵键盘 (4×4, 16按键)

#### 行线 (输出)
| GPIO | 功能 |
|------|------|
| PB3 | Row 0 |
| PB4 | Row 1 |
| PB5 | Row 2 |
| PB6 | Row 3 |

#### 列线 (输入)
| GPIO | 功能 |
|------|------|
| PB7 | Col 0 |
| PB8 | Col 1 |
| PB9 | Col 2 |
| PA15 | Col 3 |

### 输出模块
| 引脚 | GPIO | 功能 | 模式 |
|------|------|------|------|
| BUZZER | PB0 | 蜂鸣器 | Output_PP |

### 蓝牙
| 引脚 | GPIO | 功能 | 模式 |
|------|------|------|------|
| BT_STATE | PA4 | 连接状态 | Input_PD |

### 预留输入 (扩展用)
| 引脚 | GPIO | 功能 | 模式 |
|------|------|------|------|
| RESERVE_IN1 | PB1 | 预留1 | Input_PU |
| RESERVE_IN2 | PB2 | 预留2 | Input_PU |

## USART 通信配置

| UART | 波特率 | TX | RX | 用途 |
|------|--------|----|----|------|
| USART1 | 115200 | PA9 | PA10 | 调试输出 |
| USART2 | 921600 | PA2 | PA3 | 激光传感器(STP-23) |
| USART3 | 9600 | PB10 | PB11 | 蓝牙(HC-05) |

### 物理布局
```
     PB7    PB8    PB9    PA15
     ┌────┬────┬────┬────┐
PB3  │ 1  │ 2  │ 3  │ A  │
     ├────┼────┼────┼────┤
PB4  │ 4  │ 5  │ 6  │ B  │
     ├────┼────┼────┼────┤
PB5  │ 7  │ 8  │ 9  │ C  │
     ├────┼────┼────┼────┤

     └────┴────┴────┴────┘
```

### 功能说明
| 按键 | 功能 |
|------|------|
| 0-9 | 数字输入(设置阈值) |
| A | 启动系统 |
| B | 关闭系统 |
| C | 切换设置模式 |
| D | 手动蜂鸣 |
| \* | 清空输入 |
| # | 确认/保存 |
