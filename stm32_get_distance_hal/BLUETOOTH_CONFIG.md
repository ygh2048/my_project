# 蓝牙模块 AT 指令快速参考表

## 🔌 硬件连接

| MCU引脚 | 蓝牙模块 | 功能 | 说明 |
|--------|--------|------|------|
| PB10 | RX | UART3_TX | 数据发送 |
| PB11 | TX | UART3_RX | 数据接收 |
| PA4 | STATE | 状态检测 | 高=已连接, 低=未连接 |
| GND | GND | 地线 | 共地 |
| 5V | 5V | 电源 | (或3.3V) |

**波特率**: 9600, 8位数据位, 1个停止位, 无校验位

### 💡 STATE 引脚说明
- **HC-05 STATE引脚**: 
  - 未配对/未连接: **低电平 (0V)**
  - 已连接: **高电平 (3.3V)**
- **优势**: 实时硬件检测，无需软件查询
- **MCU配置**: PA4 配置为输入，下拉模式

---

## ⚡ 快速配置步骤（使用串口助手）

1. 打开串口助手，连接到蓝牙模块 UART (PB10/PB11)
2. 波特率设为 **9600** （注意：必须匹配蓝牙模块的9600！）
3. 发送行尾选择: **CR+LF** (\r\n)
4. 复制下面表中的指令，粘贴到串口助手发送

## 📋 AT 指令表

### 基础测试
| 指令 | 功能 | 响应 |
|------|------|------|
| `AT` | 测试连接 | `OK` |
| `AT+VERSION` | 获取固件版本 | `+VERSION:xxx` |
| `AT+RESET` | 软件复位 | `OK` |

### 设备信息
| 指令 | 功能 | 响应示例 |
|------|------|--------|
| `AT+NAME?` | 查询设备名称 | `+NAME:HC-05` |
| `AT+PSWD?` | 查询PIN码 | `+PSWD:1234` |
| `AT+ADDR?` | 查询蓝牙地址 | `+ADDR:98D3:71:F70225` |
| `AT+CLASS?` | 查询设备类 | `+CLASS:0,0,0` |
| `AT+UART?` | 查询波特率 | `+UART:115200,0,0` |
| `AT+ROLE?` | 查询角色 | `+ROLE:0` (0=从机, 1=主机) |
| `AT+CMODE?` | 查询配对模式 | `+CMODE:0` (0=配对, 1=自由) |
| `AT+CCON?` | 查询连接状态 | `+CCON:0` (0=断开, 1=连接) |

### 设备配置
| 指令 | 功能 | 响应 |
|------|------|------|
| `AT+NAME=LaserDistance` | 设置设备名称 | `OK` |
| `AT+PSWD=1234` | 设置PIN码 (4位数字) | `OK` |
| `AT+ROLE=0` | 设置为从机 | `OK` |
| `AT+ROLE=1` | 设置为主机 | `OK` |
| `AT+CMODE=0` | 设置配对模式 | `OK` |
| `AT+CMODE=1` | 设置自由配对 | `OK` |
| `AT+UART=115200,0,0` | 设置波特率 115200 | `OK` |
| `AT+UART=9600,0,0` | 设置波特率 9600 | `OK` |

### 连接管理
| 指令 | 功能 | 响应 |
|------|------|------|
| `AT+INQ` | 查询周围设备 | 设备地址列表 |
| `AT+INQM=0,5,9` | 设置查询模式 | `OK` |

## 🎯 推荐配置指令（按顺序执行）

复制以下指令到串口助手，逐条发送（等待OK响应）：

```
AT
AT+VERSION
AT+NAME=LaserDistance
AT+PSWD=1234
AT+ROLE=0
AT+UART=9600,0,0
AT+CMODE=0
AT+RESET
```

**预期结果：**
- 蓝牙名称: `LaserDistance`
- PIN码: `1234`
- 模式: 从机 (ROLE=0)
- 波特率: 9600
- 配对: 需要PIN

## ⚠️ 重要说明

- **所有指令必须以 \r\n 结尾**（串口助手选择CR+LF）
- **某些命令修改后需要执行 `AT+RESET` 才能生效**（如名称、角色）
- **PIN码修改不需要复位即可生效**
- **发送间隔: 至少 50-100ms**
- **MCU USART3波特率已改为9600，与蓝牙模块匹配** ✅
