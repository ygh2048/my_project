1. 项目概述
================================================================================
Smart Lab Monitoring System 是一个基于STM32F103C8T6微控制器的智能实验室监控系统，
集成了多种传感器和通信模块，实现对实验室环境的实时监测和远程控制。

主要功能：
- 电压/电流/功率实时监测
- 物品重量检测和归还状态判断
- 人体红外检测和自动照明控制
- OLED显示屏状态显示
- ESP8266 WiFi模块网络连接
- OneNET物联网平台数据上传和远程控制
- 按键本地控制
- 继电器控制照明和电源

2. 系统架构
================================================================================

2.1 硬件架构
--------------------------------------------------------------------------------
MCU: STM32F103C8T6 (ARM Cortex-M3, 72MHz, 64KB Flash, 20KB RAM)

引脚分配：
- PA0: ADC电压采样 (电源电压)
- PA2: ADC电流采样 (通过1K电阻)
- PA11: 照明继电器控制
- PA12: 总电源继电器控制
- PB3: HX711时钟信号 (SCK)
- PB4: HX711数据信号 (DOUT)
- PB5: HC-SR505人体红外检测
- PB10: ESP8266串口接收 (RX)
- PB11: ESP8266串口发送 (TX)
- PC13: LED状态指示灯
- PC14: ESP8266复位控制
- PC15: ESP8266使能控制

2.2 软件架构
--------------------------------------------------------------------------------
项目采用模块化设计，主要分为以下层次：

├── User/                          # 用户应用层
│   └── main.c                     # 主程序入口
├── Drivers/                       # 驱动层
│   ├── BSP/                       # 板级支持包
│   │   ├── ADC/                   # ADC模数转换
│   │   ├── ESP8266/               # WiFi通信模块
│   │   ├── HC_SR505/              # 人体红外传感器
│   │   ├── HX711/                 # 压力传感器
│   │   ├── KEY/                   # 按键输入
│   │   ├── LED/                   # LED指示灯
│   │   ├── OLED/                  # OLED显示屏
│   │   ├── ONENET/                # OneNET物联网平台
│   │   ├── RELAY/                 # 继电器控制
│   │   └── WDG/                   # 看门狗
│   └── SYSTEM/                    # 系统服务层
│       ├── delay/                 # 延时服务
│       ├── sys/                   # 系统配置
│       ├── tick/                  # 系统时钟
│       └── usart/                 # 串口通信
├── Library/                       # STM32标准库
│   ├── inc/                       # 头文件
│   └── src/                       # 源文件
└── Output/                        # 编译输出

3. 执行流程
================================================================================

3.1 系统启动流程
--------------------------------------------------------------------------------
1. 系统上电复位
2. 执行 system_init() 系统初始化：
   - 时钟初始化 (72MHz)
   - 延时服务初始化
   - 串口初始化 (115200bps)
   - LED初始化
   - ADC初始化
   - 继电器初始化
   - 按键初始化
   - OLED初始化并显示启动信息
   - 内存池初始化 (MQTT使用)
   - 系统状态结构体清零
   - 开启总电源继电器

3. 外设模块初始化：
   - HX711压力传感器初始化 (设置零点)
   - HC-SR505人体红外传感器初始化
   - OneNET物联网平台初始化
   - WiFi连接建立
   - 订阅控制主题

4. 进入主循环

3.2 主循环执行流程 (5ms周期)
--------------------------------------------------------------------------------
主循环采用非阻塞设计，每个周期执行以下任务：

┌─────────────────────────────────────────────────────────────┐
│                    主循环 (5ms周期)                          │
├─────────────────────────────────────────────────────────────┤
│  1. 按键处理 (process_key) - 实时响应                      │
│                                                             │
│  2. 传感器数据更新 (每100ms)                               │
│     ├── ADC电压/电流采样                                   │
│     ├── HX711重量检测                                      │
│     └── HC-SR505人体检测                                   │
│                                                             │
│  3. OLED显示更新 (每500ms)                                 │
│     ├── 电压显示 (V: X.XV)                                 │
│     ├── 归还状态 (Return: YES/NO)                          │
│     ├── 电流显示 (I: XX.XmA)                               │
│     ├── 功率显示 (P: XXX.XmW)                              │
│     ├── 重量显示 (W: XXXg)                                 │
│     └── 照明状态 (Light: ON/OFF)                           │
│                                                             │
│  4. 数据上传 (每4秒)                                       │
│     ├── 串口打印状态信息                                   │
│     └── OneNET平台数据上传                                 │
│                                                             │
│  5. WiFi连接检查 (每20秒)                                  │
│     ├── WiFi连接状态检查                                   │
│     └── TCP连接状态检查                                    │
│                                                             │
│  6. OneNET命令处理                                         │
│     ├── 接收平台下发命令                                   │
│     └── 执行远程控制                                       │
│                                                             │
│  7. UART命令处理 (process_uart_cmd)                        │
│                                                             │
│  8. LED状态指示 (每500ms闪烁)                              │
│                                                             │
│  9. 延时5ms                                                │
└─────────────────────────────────────────────────────────────┘

4. 核心模块说明
================================================================================

4.1 系统状态管理 (system_status_t)
--------------------------------------------------------------------------------
系统使用统一的结构体管理所有状态信息：

typedef struct {
    float voltage;          // 电压(V)
    float current;          // 电流(mA)
    float power;            // 功率(mW)
    int32_t weight;         // 质量(g)
    uint8_t is_returned;    // 物品归还状态 (0=未归还, 1=已归还)
    uint8_t human_detected; // 人体检测 (0=无人, 1=有人)
    uint8_t light_status;   // 照明状态 (0=关, 1=开)
    uint8_t power_status;   // 总电源状态 (0=关, 1=开)
} system_status_t;

4.2 ADC模块 (adc.c/adc.h)
--------------------------------------------------------------------------------
功能：电压和电流数据采集
- PA0: 直接采样电源电压
- PA2: 采样1K电阻压降计算电流
接口：
- void adc_init(void)                    // 初始化
- uint16_t adc_get_value(uint8_t ch)     // 获取ADC原始值
- float adc_get_voltage(uint8_t ch)      // 获取电压值(V)

4.3 HX711压力传感器 (hx711.c/hx711.h)
--------------------------------------------------------------------------------
功能：物品重量检测和归还判断
- PB3: 时钟信号 (SCK)
- PB4: 数据信号 (DOUT)
接口：
- void hx711_init(void)                  // 初始化
- uint32_t hx711_read(void)              // 读取原始数据
- void hx711_get_maopi(void)             // 获取零点值
- void hx711_get_weight(void)            // 获取重量

4.4 HC-SR505人体红外 (hc_sr505.c/hc_sr505.h)
--------------------------------------------------------------------------------
功能：人体存在检测，控制自动照明
- PB5: 红外检测输入
接口：
- void hc_sr505_init(void)               // 初始化
- uint8_t hc_sr505_detect(void)          // 检测人体 (0=无人, 1=有人)

4.5 继电器控制 (relay.c/relay.h)
--------------------------------------------------------------------------------
功能：照明和电源控制
- PA11: 照明继电器
- PA12: 总电源继电器
接口：
- void relay_init(void)                  // 初始化
- void relay_light_on/off(void)          // 照明控制
- void relay_power_on/off(void)          // 电源控制

4.6 OLED显示 (oled.c/oled.h)
--------------------------------------------------------------------------------
功能：状态信息显示
- 软件I2C接口
接口：
- void OLED_Init(void)                   // 初始化
- void OLED_Clear(void)                  // 清屏
- void OLED_ShowString(uint8_t, uint8_t, uint8_t*) // 显示字符串

4.7 ESP8266 WiFi模块 (esp8266.c/esp8266.h)
--------------------------------------------------------------------------------
功能：网络通信
- PB10/PB11: 串口通信
- PC14: 硬件复位
- PC15: 使能控制
接口：
- void esp8266_init(void)                // 初始化
- uint8_t esp8266_send_cmd(char*, char*, int) // 发送AT命令
- uint8_t* esp8266_get_ipd(uint32_t)     // 获取接收数据

4.8 OneNET物联网平台 (onenet.c/onenet.h)
--------------------------------------------------------------------------------
功能：数据上传和远程控制
产品ID: 489VMXhRtU
设备名: WORK
接口：
- uint8_t onenet_init(void)              // 初始化
- uint8_t onenet_connect(void)           // 连接平台
- void onenet_send_data(void)            // 上传数据
- void onenet_recv_process(uint8_t*)     // 处理命令
- void onenet_subscribe(void)            // 订阅主题

4.9 按键控制 (key.c/key.h)
--------------------------------------------------------------------------------
功能：本地手动控制
接口：
- void key_init(void)                    // 初始化
- uint8_t key_scan(uint8_t)              // 按键扫描

5. 控制逻辑
================================================================================

5.1 自动照明控制
--------------------------------------------------------------------------------
- 检测到人体存在且总电源开启 → 自动开灯
- 无人检测到 → 自动关灯
- 远程控制优先级高于自动控制 (有效期400ms)

5.2 物品归还判断
--------------------------------------------------------------------------------
- 重量 ≥ 500g → 判定为已归还
- 重量 < 500g → 判定为未归还

5.3 远程控制
--------------------------------------------------------------------------------
OneNET平台支持以下控制：
- light: 照明开关控制
- open_close: 总电源开关控制

5.4 WiFi连接维护
--------------------------------------------------------------------------------
- 每20秒检查WiFi和TCP连接状态
- 连续失败2次 → 硬件复位ESP8266模块

================================================================================
6. 数据流程
================================================================================

6.1 传感器数据采集流程
--------------------------------------------------------------------------------
ADC采样 → 电压/电流计算 → 功率计算
HX711读取 → 重量计算 → 归还状态判断
HC-SR505检测 → 人体状态更新

6.2 显示更新流程
--------------------------------------------------------------------------------
系统状态 → OLED显示格式化 → 屏幕刷新 (500ms周期)

6.3 数据上传流程
--------------------------------------------------------------------------------
系统状态 → 数据格式化 → MQTT协议封装 → ESP8266发送 → OneNET平台 (4秒周期)

6.4 远程控制流程
--------------------------------------------------------------------------------
OneNET平台 → MQTT消息接收 → 命令解析 → 继电器控制 → 状态更新

7. 通信协议
================================================================================

7.1 串口通信
--------------------------------------------------------------------------------
- 波特率: 115200bps
- 数据格式: 8位数据位，无校验，1位停止位
- 用于调试信息输出和UART命令接收

7.2 MQTT协议 (OneNET)
--------------------------------------------------------------------------------
- 服务器: mqtts.heclouds.com:1883
- 客户端ID: 设备唯一标识
- 订阅主题: 控制命令接收
- 发布主题: 传感器数据上传

7.3 数据格式
--------------------------------------------------------------------------------
上传数据格式 (JSON):
{
    "light": 0/1,           // 照明状态
    "open_close": 0/1,      // 电源状态
    "mv": XXXX,             // 电压(mV)
    "ma": XXXX,             // 电流(mA)
    "mp": XXXX,             // 功率(mW)
    "weight": XXXX          // 重量(g)
}

9. 故障排除
================================================================================

9.1 常见问题
--------------------------------------------------------------------------------
1. WiFi连接失败
   - 检查ESP8266模块供电和连接
   - 验证AT命令响应

2. 传感器数据异常
   - 检查ADC参考电压 (3.3V)
   - 验证HX711模块连接

3. OLED显示异常
   - 检查I2C时序和地址
   - 验证供电电压

4. OneNET连接失败
   - 检查网络连接
   - 验证产品ID和密钥

9.2 调试信息
--------------------------------------------------------------------------------
系统通过串口输出详细的调试信息：
- [AUTO] 自动控制信息
- [HX711] 传感器状态
- [ESP8266] 网络状态
- [ONENET] 平台通信状态
