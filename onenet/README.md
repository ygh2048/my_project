# 智能实验台监控系统 - STM32F103C8T6

## 🎯 项目概述

这是一个基于STM32F103C8T6微控制器的**智能实验台监控系统**，集成了多种传感器和通信模块，实现以下功能：

- ⚡ **电能监测**：实时采集电压、电流、功率数据
- ⚖️ **重量检测**：通过HX711传感器精确测量物品重量
- 👤 **人体检测**：HC-SR505红外传感器自动检测人体存在
- 💡 **智能照明**：根据人体检测自动控制灯光，支持远程控制
- 🌐 **云平台集成**：通过ESP8266 WiFi模块接入OneNET云平台
- 📱 **多种交互**：支持物理按键、串口命令、OLED显示、云端控制

### 核心特性
- **高精度采样**：12位ADC采样，HX711 24位高精度
- **低功耗设计**：待机功耗极低，持续运行
- **实时处理**：基于SysTick的1ms精确调度
- **安全可靠**：独立看门狗保护，内存池管理
- **易于扩展**：模块化代码结构，便于添加新功能

## 📁 项目文件结构及功能说明

### APP/ - 应用层模块
应用层包含系统业务逻辑的核心实现，分为配置、显示、输入、运行时管理和系统管理五个模块。

#### app_config.h
- **功能**：应用层全局配置常量
- **内容**：
  - 传感器阈值（重量判定）
  - 调度周期配置（5ms基础节拍）
  - WiFi自恢复策略参数
  - 测量修正系数（电压、电流、采样电阻）

#### app_display.c / app_display.h
- **功能**：OLED显示管理模块
- **功能点**：
  - 实时显示系统状态（电压、电流、功率、重量等）
  - 右对齐显示算法
  - 四行显示分组展示不同信息
- **调用周期**：500ms

#### app_input.c / app_input.h
- **功能**：输入处理模块（按键和串口命令）
- **按键功能**：
  - KEY0：切换电源状态
  - KEY1：HX711秤去皮操作
- **串口命令支持**：PON、POFF、LON、LOFF、ZERO、INFO、HX711、ADC、TEST
- **用途**：本地控制和调试诊断

#### app_runtime.c / app_runtime.h
- **功能**：运行时数据管理和状态维护
- **管理数据**：system_status_t结构体
  - 实时参数：电压、电流、功率、重量
  - 状态标志：电源、灯光、人体检测、物品返回状态
- **特殊功能**：
  - 远程灯光强制保持超时计时
  - 网络命令处理保护标记
- **重要全局变量**：sys_status

#### app_system.c / app_system.h
- **功能**：系统管理和协调模块
- **职责**：
  - 系统初始化（硬件外设、传感器、网络）
  - 传感器数据更新和处理
  - 自动灯光控制逻辑
  - 状态上报到云平台
  - 网络连接检测和恢复

### HARDWARE/ - 硬件驱动层

#### ADC/ - 模数转换器驱动
```
功能：采集电压和电流数据
- adc_init()：初始化ADC，配置通道0和通道1
- adc_get_voltage()：读取指定通道的电压值（单位：V）
硬件：STM32F103 12位ADC
```

#### ESP8266/ - WiFi模块驱动
```
功能：WiFi通信和网络连接
- esp8266_init()：初始化串口和GPIO
- esp8266_check_wifi()：检查WiFi连接状态
- esp8266_check_tcp()：检查TCP连接状态
- esp8266_hw_reset_only()：硬件复位
模块：ESP8266 WiFi模块（USART3通信）
```

#### HC_SR505/ - 人体红外传感器驱动
```
功能：检测人体存在
- hc_sr505_init()：初始化GPIO
- hc_sr505_detect()：读取传感器状态（1=检测到，0=未检测）
传感器：HC-SR505红外运动传感器
```

#### HX711/ - 重量传感器驱动
```
功能：高精度重量测量
- hx711_init()：初始化GPIO和读取参数
- hx711_get_maopi()：读取零点校准值
- hx711_get_weight()：读取重量数据
- 全局变量：hx711_buffer, hx711_maopi, hx711_weight
传感器：HX711 24位ADC + 压力传感器
```

#### KEY/ - 按键驱动
```
功能：按键扫描和消抖
- key_init()：初始化按键GPIO
- key_scan(mode)：扫描按键状态
- 支持：KEY0_PRES, KEY1_PRES
```

#### LED/ - LED指示灯驱动
```
功能：LED状态指示
- led_init()：初始化LED GPIO
- LED0(x)：控制LED0亮灭（0=亮，1=灭）
- LED0_TOGGLE()：LED0翻转
```

#### OLED/ - OLED显示屏驱动
```
功能：OLED 128x32像素显示
- OLED_Init()：初始化显示屏
- OLED_Clear()：清屏
- OLED_ShowString(row, col, text)：显示字符串
- 支持4行16列的字符显示
```

#### ONENET/ - OneNET云平台驱动
```
模块说明：
- onenet.c/h：OneNET平台连接和数据管理
  - onenet_init()：初始化WiFi和MQTT
  - onenet_connect()：连接到OneNET云平台
  - onenet_send_data()：上报数据
  
- onenet_protocol.c/h：MQTT协议实现
  - 安全的JSON解析
  - OneJSON格式数据编码
  
- mem_pool.c/h：内存池管理
  - 为MQTT数据包提供内存分配
  - 防止内存碎片化
  
- mqttkit.c/h：MQTT工具函数
  
- base64.c/h：Base64编码解码
  
- hmac_sha1.c/h：HMAC-SHA1加密
  用于MQTT连接认证
```

#### RELAY/ - 继电器控制驱动
```
功能：电源和灯光继电器控制
- relay_init()：初始化继电器GPIO
- relay_power_on/off()：控制电源继电器
- relay_light_on/off()：控制灯光继电器
硬件：两个12V继电器模块
```

#### WDG/ - 看门狗驱动
```
功能：系统保护和异常恢复
- wdg_init(ms)：初始化独立看门狗
- wdg_feed()：喂狗，复位计数器
```

### SYSTEM/ - 系统基础库

#### delay/ - 延时函数库
```
基于SysTick的精确延时实现：
- delay_init()：初始化延时函数
- delay_us(nus)：微秒级延时
- delay_ms(nms)：毫秒级延时
特点：非阻塞式，精确度高
```

#### sys/ - 系统配置库
```
功能：系统时钟、GPIO和中断配置
- sys_stm32_clock_init(clk)：初始化系统时钟至72MHz
- GPIO引脚配置
- 中断保护宏
```

#### tick/ - 系统计时器
```
功能：1ms精度的系统滴答计时器
- tick_init()：初始化SysTick（HCLK/8）
- SysTick_Handler()：1ms中断处理
- get_tick()：获取系统运行时间（ms）
特点：作为系统心跳，驱动各模块调度
```

#### usart/ - 串口通信库
```
功能：USART通信和调试输出
- usart_init(clk, baud)：初始化串口1（115200 8N1）
- 支持printf重定向到串口
- 中断接收缓冲区（g_usart_rx_buf）
- 接收状态标记（g_usart_rx_sta）
```

### CORE/ - CMSIS核心库
```
STM32F103芯片级文件和CMSIS标准库
- stm32f103xe.h：寄存器定义
- system_stm32f1xx.c：系统初始化
- startup_stm32f103xe.s：启动汇编代码
- core_cm3.h：Cortex-M3核心
```

### USER/ - 主程序
#### main.c
```
功能：系统主程序和调度循环
组成：
1. 初始化阶段
   - 系统初始化（app_system_init）
   
2. 主循环调度（基于5ms节拍）
   - 传感器更新（100ms周期）
   - 显示刷新（500ms周期）
   - 状态上报（4s周期）
   - 网络检查（20s周期）
   - 按键处理（连续）
   - 串口命令处理（连续）
```

### Output/ - 编译输出
```
构建产物目录：
- atk_f103.axf：可执行文件（调试符号）
- atk_f103.hex：十六进制固件文件（烧录用）
- atk_f103.map：链接器映射文件
- *.lst：列表文件（汇编代码）
- *.d：依赖文件
- *.crf：交叉引用文件
```

## 🚀 快速开始

### 编译步骤
1. 使用 Keil MDK v5.0 或更高版本
2. 打开 `USER/atk_f103.uvprojx` 项目文件
3. 选择 USART 目标配置
4. 按 Ctrl+B 编译项目
5. 编译成功后输出：0 Error(s), 几个 Warning(s)

### 烧录步骤
1. 使用 ST-Link 或其他 STM32 烧录器
2. 烧录 `Output/atk_f103.hex` 文件到 Flash
3. 复位开发板，系统自动启动

### 调试输出
1. 使用串口助手连接 USART1 (COM口)
2. 波特率：115200，8数据位，1停止位，无奇偶校验
3. 系统启动时显示欢迎信息和初始化进度
4. 支持串口命令交互

### 串口命令参考
```
PON      - 开启电源
POFF     - 关闭电源
LON      - 开启灯光（需要电源已开启）
LOFF     - 关闭灯光
INFO     - 显示系统状态信息
HX711    - 显示HX711传感器调试信息
ADC      - 显示ADC采样调试信息
TEST     - 运行硬件自检
ZERO     - HX711去皮（当前预留）
```

## 🔐 故障排除

### 常见问题

**Q: 编译时出现"未定义引用"错误**
- A: 检查是否所有源文件都已添加到项目中
- 检查包含路径是否正确配置

**Q: 串口输出乱码**
- A: 检查波特率是否为 115200
- 检查USART初始化参数是否正确

**Q: OLED显示不正常**
- A: 检查I2C通信引脚接线
- 运行TEST命令检查硬件自检

**Q: WiFi连接失败**
- A: 检查ESP8266模块是否上电
- 检查USART3通信是否正常
- 检查OneNET配置参数是否正确

**Q: 重量测量偏差大**
- A: 运行KEY1按键进行HX711去皮
- 检查传感器是否受力正确
- 调整app_config.h中的修正系数
