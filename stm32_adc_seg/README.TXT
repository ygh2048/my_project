================================================================================
  STM32F103 ADC电压监测系统 - 代码设计思路
================================================================================

【项目概述】
  基于STM32F103C8T6的实时电压监测系统，通过ADC采集模拟电压，使用4位共阳极
  数码管显示，支持电压报警功能（蜂鸣器+LED）。采用定时器中断驱动数码管扫描，
  实现稳定无闪烁显示。

【硬件架构】
  ┌─────────────────────────────────────────────────────────────┐
  │ 微控制器：STM32F103C8T6 (ARM Cortex-M3, 72MHz)             │
  ├─────────────────────────────────────────────────────────────┤
  │ ADC输入：PB0 (ADC1_CH8) - 电压传感器输入 (0-3.3V)         │
  │ 数码管：4位共阳极七段显示，段线分散在GPIOA/GPIOB          │
  │         - 段码: PA1,PA2,PA5,PA11, PB12,PB13,PB14,PB15      │
  │         - 位选: PA0(千位), PA3(百位), PA4(十位), PA12(个位)│
  │ 按键：PB6(KEY0), PB7(KEY1) - 切换显示模式（原始/电压）    │
  │ LED：PB5(LED0) - 报警闪烁指示                               │
  │ 蜂鸣器：PB8(BEEP) - 报警声音提示（低电平触发）            │
  │ 串口：UART1 (PA9/PA10, 115200baud) - 调试信息输出          │
  └─────────────────────────────────────────────────────────────┘

【核心设计思路】

一、模块化HAL架构
   ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
   │   main.c     │───>│  HARDWARE/   │───>│ STM32 Lib    │
   │  (应用层)    │    │  (驱动层)    │    │ (底层HAL)    │
   └──────────────┘    └──────────────┘    └──────────────┘
                            │
                ┌───────────┼───────────┬───────────┬──────────┐
                │           │           │           │          │
              ADC/        SEG/        KEY/       BEEP/       LED/
            (采样)    (数码管显示)   (按键)    (蜂鸣器)    (指示灯)

   每个模块独立封装：
   - XXX_Init()  : 模块初始化（RCC时钟+GPIO+外设配置）
   - XXX_Task()  : 周期性任务（如SEG_Task扫描显示）
   - XXX_API()   : 对外接口（如ADC1_ReadAverage读取平均值）

二、定时器中断驱动架构
   【问题】：主循环用delay_ms(1)轮询，CPU空转浪费，数码管扫描不稳定
   【解决】：TIM3定时器1ms中断 + 中断服务程序(ISR)处理实时任务

   ┌─────────────────────────────────────────────────────────────┐
   │ TIM3_IRQHandler (每1ms触发)                                 │
   ├─────────────────────────────────────────────────────────────┤
   │  1. SEG_Task()      - 数码管扫描（4位轮流刷新，无闪烁）    │
   │  2. sample_timer++  - ADC采样计时（50ms采样一次）          │
   │  3. blink_timer++   - 报警闪烁计时（500ms翻转LED/蜂鸣器）  │
   │  4. debug_timer++   - 调试信息输出计时（1000ms打印一次）   │
   └─────────────────────────────────────────────────────────────┘

   主循环(while(1))不再阻塞：
   - 全速运行，无delay_ms(1)
   - 检查计时器标志位，执行对应任务（ADC采样/报警/按键）
   - 提高响应速度，降低CPU占用

三、共阳极数码管动态扫描
   【原理】：4位数码管共用8条段线(a-g+dp)，通过快速切换位选实现多位显示
   【扫描频率】：1ms刷新一位 → 4ms完整扫描一轮 → 250Hz刷新率（人眼无闪烁）

   时序流程（每次SEG_Task调用）：
   ┌────────────────────────────────────────────────────────────┐
   │ Step 1: 关闭所有位选 (防止重影)                            │
   │         → PA0/PA3/PA4/PA12 输出高电平（共阳极高电平=关）  │
   │ Step 2: 短延时10个NOP (等待GPIO电平稳定)                   │
   │ Step 3: 写入当前位段码到段线                               │
   │         → 低电平点亮对应段（如0x3F显示"0"）               │
   │ Step 4: 打开当前位选 (激活该位显示)                        │
   │         → 对应位选引脚输出低电平（共阳极低电平=开）       │
   │ Step 5: scan_index++ (下次刷新下一位)                      │
   └────────────────────────────────────────────────────────────┘

   关键配置：
   - SEG_ACTIVE_HIGH = 0  (共阳极段码低电平有效)
   - DIGIT_ACTIVE_HIGH = 0 (共阳极位选低电平有效)

四、ADC采样与滤波
   ┌──────────────────────────────────────────────────────────┐
   │ ADC1_ReadAverage(ADC_CHANNEL_VSENSE, 8)                  │
   ├──────────────────────────────────────────────────────────┤
   │  1. 连续读取8次ADC原始值 (12位, 0-4095)                 │
   │  2. 累加求平均 → 滤除高频噪声                            │
   │  3. ADC1_ToMilliVolts(adc_raw) 转换为毫伏               │
   │     公式: voltage_mv = (adc_raw * 3300) / 4095          │
   └──────────────────────────────────────────────────────────┘

   采样周期：50ms (sample_timer>=50时触发)
   - 频率适中，兼顾实时性和稳定性
   - 避免过度采样占用CPU资源

五、电压显示格式化
   【模式1】原始ADC值 (0-4095)
     显示格式：直接显示4位十进制数字
     示例：ADC=1820 → 显示 "1820"

   【模式2】电压值 (X.XXV)
     显示格式：千位=整数位，百位=小数点+小数第1位，十位=小数第2位，个位=V
     转换流程：
       1820mV → 182 厘伏 (voltage_mv / 10)
       → 千位=1, 百位=8., 十位=2, 个位=V
       → 显示 "1.82V"

     小数点处理：
       display_dots = (1 << 3);  // 小数点在千位后（bit3）

六、报警逻辑
   ┌──────────────────────────────────────────────────────────┐
   │ 触发条件：voltage_mv < 1000mV 或 voltage_mv > 2500mV    │
   ├──────────────────────────────────────────────────────────┤
   │ 动作1：LED0 闪烁 (500ms周期翻转)                         │
   │ 动作2：蜂鸣器 "哔哔" 声 (跟随LED同步翻转)               │
   │ 动作3：UART输出报警信息 (仅首次触发时打印)              │
   │         "ALARM! Voltage: X.XXV, Threshold: 1.00V~2.50V" │
   └──────────────────────────────────────────────────────────┘

   状态机：
   - alarm_active=0 → 正常状态 (LED常灭，蜂鸣器关)
   - alarm_active=1 → 报警状态 (进入闪烁逻辑)
   - 电压恢复正常范围 → 自动解除报警

七、按键交互
   ┌──────────────────────────────────────────────────────────┐
   │ KEY0/KEY1 任意按下 → 切换显示模式                        │
   ├──────────────────────────────────────────────────────────┤
   │ DISPLAY_RAW  ?  DISPLAY_VOLT                             │
   │ (原始ADC值)     (格式化电压)                              │
   └──────────────────────────────────────────────────────────┘

   按键扫描：
   - KEY_Scan(0) 内部10ms消抖
   - 状态机防止连续触发（key_up标志位）

【关键数据流】

  PB0(硬件) → ADC1_CH8 → 12位数字量 → 8次平均 → 毫伏值
                ↓
            SEG_DisplayVoltage() → 格式化 → display_digits[]
                ↓
            TIM3_IRQHandler → SEG_Task() → 动态扫描 → 数码管显示

【文件组织】
  work/
  ├── USER/
  │   ├── main.c              - 主程序（初始化+主循环+业务逻辑）
  │   ├── stm32f10x_conf.h    - 库配置（启用ADC/GPIO/TIM等外设）
  │   ├── stm32f10x_it.c      - 中断向量表（预留TIM3_IRQHandler）
  │   └── USART.uvprojx       - Keil工程文件
  ├── HARDWARE/
  │   ├── ADC/adc.c           - ADC驱动（初始化+采样+电压转换）
  │   ├── SEG/seg.c           - 数码管驱动（扫描+显示API）
  │   ├── KEY/key.c           - 按键驱动（扫描+消抖）
  │   ├── BEEP/beep.c         - 蜂鸣器驱动（低电平触发）
  │   ├── LED/led.c           - LED驱动（GPIO输出）
  │   └── TIMER/timer.c       - 定时器驱动（TIM3中断配置+ISR）
  ├── SYSTEM/
  │   ├── delay/delay.c       - 延时函数（基于SysTick）
  │   ├── sys/sys.h           - 系统宏定义（位带操作等）
  │   └── usart/usart.c       - 串口驱动（printf重定向）
  └── STM32F10x_FWLib/        - ST标准外设库

【调试与测试流程】
  1. 上电启动 → 串口输出系统信息
  2. 数码管测试 → 每位依次显示0-9（验证引脚映射）
  3. 显示1234 → 5秒静态显示（验证扫描稳定性）
  4. 进入ADC采集 → 实时显示电压值
  5. 按键测试 → 切换原始值/电压值显示
  6. 报警测试 → 手动调整输入电压超限，验证LED/蜂鸣器

【优化亮点】
  ? 定时器中断替代轮询 - 提升响应速度，降低CPU占用
  ? 8次采样平均 - 抑制ADC噪声，提高测量精度
  ? 动态扫描优化 - 关闭位选+延时+写段码，消除重影
  ? 模块化设计 - 每个外设独立封装，易于维护扩展
  ? volatile关键字 - 确保中断/主循环数据同步

【常见问题排查】
  问题1：数码管显示乱码/反白
    → 检查 seg.h 中 SEG_COMMON_ANODE 宏定义是否与硬件匹配
  
  问题2：千位亮，其他位暗淡
    → 位选逻辑反转，需启用 #define SEG_COMMON_ANODE
  
  问题3：编译错误 "Undefined symbol TIM_XXX"
    → Keil工程未添加 stm32f10x_tim.c，需手动加入
  
  问题4：数码管闪烁严重
    → 检查 TIM3_Int_Init 是否正确调用，确认1ms中断正常触发

【扩展方向】
  → 增加多通道ADC采样（温度、电流等）
  → 添加EEPROM存储报警阈值
  → 实现按键长按/短按不同功能
  → 增加WiFi/蓝牙模块，实现远程监控

【绘图工具推荐】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. draw.io (推荐，免费开源)
   - 网址：https://app.diagrams.net/
   - 优点：无需安装，浏览器直接使用，导出PNG/PDF
   - 技巧：选择"Basic Flowchart"模板，拖拽图形，右键设置样式

2. Microsoft Visio (专业工具)
   - 优点：图形丰富，排版精美，与Office集成
   - 模板：文件 → 新建 → 流程图 → 基本流程图

3. ProcessOn (在线协作)
   - 网址：https://www.processon.com/
   - 优点：云端保存，团队协作，模板丰富

4. Mermaid (代码绘图，适合Markdown文档)
   - 语法示例：
     ```mermaid
     graph TD
         A[开始] --> B{判断条件}
         B -->|Y| C[执行A]
         B -->|N| D[执行B]
     ```
   - 优点：纯文本描述，版本管理友好

【绘图通用规范】
  □ 起止符号：椭圆/圆角矩形
  □ 处理操作：矩形
  □ 判断分支：菱形（标Y/N）
  □ 循环结构：双线矩形或标注"loop"
  □ 连接线：实线箭头（顺序流程），虚线箭头（返回/跳转）
  □ 注释：用虚线框或右侧文本框说明
  □ 配色：主流程用蓝色，关键步骤用红色，循环用绿色

【课程设计/答辩建议】
  1. 主程序流程图 → 放在前面，展示整体架构
  2. 中断流程图 → 重点讲解，体现实时性设计
  3. 核心算法流程图 → 详细说明，展示技术深度
  4. 子程序流程图 → 选取1-2个典型模块即可

  答辩时配合代码讲解，指出流程图与代码的对应关系！
